# Medclinic API

## Sobre o projeto

Mini-Projeto API para o gerenciamento de uma clínica médica de pequeno porte.


## Tecnologias utilizadas

- Node.js
- TypeScript
- Express
- Git
- GitHub

## Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:
- Node.js
- npm
- Git

## Como instalar e executar

Copie e cole os códigos abaixo no terminal.

```bash
npm run build
npm start

ou

npm run dev
```
